# Group

Groups $G$ are algebraic structures which are set and has a binary operation $\bigoplus$ that combines two elements $a, b$ of the set to produce a third element $a\bigoplus b$ in the set. The operation is said to have following properties:

1. Closure: $a\oplus b=c\in G$
2. Associative: $(a\oplus b)\oplus c = a\oplus(b\oplus c)$
3. Existence of Identity element: $a\oplus 0 = 0\oplus a = a$
4. Existence of **unique** inverse element for every element of the set: $a\oplus b=0$

Example: $\mathbb{Z}$ is an abelian group while $\mathbb{N}$ is not a group as it doesn't satisfy inverse element property.

> [!question] Prove uniqueness of inverse.
> Take two elements $b\neq c\in G$ such that $a\cdot b=1$ and $a\cdot c=1$. Prove with contradiction $b=c$.

- A set with only closure and associativity, is called **Semigroup**.
- **Monoid** has Closure, associativity, Identity.

Groups which satisfy an additional property: *commutativity* on the set of elements are known as **Abelian groups**.

> [!question] One very obvious question that comes to mind is Why abelian varieties are so significant in cryptography?
> First these structures provide perfect abstractions to instantiations of them like a group of integers $\mathbb{\mathbb{Z}}$, and due to this abstraction, we can prove theorems for these structures that won't be possible without introducing their properties like commutativity in abelian groups.[^1]

Now, set underlying the group can have finite elements, namely [Finite Groups](https://en.wikipedia.org/wiki/Finite_group). For example: $\mathbb{Z}_{5}$, having elements ${0, 1, 2, 3, 4}$.

> [!question] Prove in a finite group of order m: $g^{m}=e$.

Isomorphism in groups: Two groups are isomorphic to each other if there exists a map from $f:G\to H$, and written as $G \simeq H$.
- $f$ is bijection
- group operation commutes: $f(g_{1}\oplus_{G} g_{2})=f(g_{1})\oplus_{H}f(g_{2})$

Direct product in groups: Given two group $G(\oplus_{G}),H(\oplus_{H})$, direct group is written as $G\times H:(g,h)$ where $g\in G,h\in H$, containing $|G|\cdot |H|$ elements, and group operation is applied component wise: $(g,h)\oplus(g',h')=(g \oplus_{G} g'),(h \oplus_{H}h')$.

> [!tip] Using this, [[crt]] is proven.

Symmetric Group $S_{n}$: set of all permutation of set of indices $\{ 1,2,\dots,n \}$. Finite group of order $n!$
- Example: $S_{2}$ has two elements $e,\tau$. Identify both its elements, identity, and inverse.

> **Prove** $S_{n}$ for $n\geq3$ is non-abelian.

Symmetric group of a set $T$, defined as $\text{Sym}(T)=\{ \text{all bijections }a:T\to T \}$ under composition $a\circ b(t)=a(b(t))$, where $a,b$ are bijections of the set. This can be referred to as [automorphism group](https://en.wikipedia.org/wiki/Automorphism_group) of T, written as $\text{Aut}(T)$.

We usually define symmetric groups using particular permutation elements. Let $x=(1\ 2\ 3)$ and $y=(1\ 2)$. According to the rules, $x^{3}=1,\ y^{2}=1,\ yx=x^{2}y$. And the six elements of the group are $\{ 1,x,y,x^{2},xy,x^{2}y \}$.

## Subgroup
Subset $H$ of $G$ satisfying group axioms. Expressed as $H\leq G$.
- Improper or Trivial subgroups: $G$ itself and identity element.
- Proper subgroups: all other subgroups.

> [!info] Theorem:
> - Non empty subset $H \subset G$ is a subgroup iff H's operation is multiplication.
> - For subgroup $H\leq G$ and $h\in G$, $hH=H=Hh$. Can be generalised to any set $S \subset H\implies SH=H=HS$.

> [!info] [Lagrange's theorem](https://en.wikipedia.org/wiki/Lagrange%27s_theorem_(group_theory)): states that for any finite group $G$, order of every subgroup $H$ divides order of group $G$. Formally, for $H$ being subgroup of $G$, $|G|=n|H|$, for some integer $n$.
> Proof: Take an element $r_{1}\in G, r_{1}\notin H$, then $|r_{1}H|=|H|$. Since $r_{1}H,H$ are disjoint, then $|r_{1}H \cup H|=2|H|$. Take $n$ such subgroups of $G$, such that $|r_{1}H\cup r_{2}H\cup\dots \cup r_{n}H|=n|H|=G$.

Corollary: let $G$ be a group, and $g\in G$, then order of $g$ divides $|G|$.

Theorem: If $H_{1},H_{2},\dots$ are subgroups, then $H_{1} \cap H_{2}\cap\dots$ is subgroup of each of $H_{1},H_{2},\dots$.
- Independent elements: $g_{i}\notin\langle g_{1},\dots,g_{i-1},g_{i+1},\dots,g_{m} \rangle$, i.e. $g_{i}$ isn't generated by any of the other elements.
- Every finite group has independent set of generators which can be used to define relations.
- Defining relation: Relation defined using independent elements.

## Cyclic Groups
Finite groups that can be represented as $g,g\bigoplus g,\cdots$, i.e. a generator $g$, which can create the complete set with the group operation, written $H=\langle g \rangle$.

> **Fundamental theorem of finite cyclic groups**: if $\mathbb{G}$ is a finite cyclic group such that $|G|=n$, and $k:k|n$, then, $\mathbb{G}[k]$ refers to unique finite cyclic subgroup of $\mathbb{G}$ with order $k$.
> Proof of above theorem follows from Lagrange's theorem.

Theorem: Every group of composite order has proper subgroups.

> [Cauchy's theorem](https://en.wikipedia.org/wiki/Cauchy%27s_theorem_(group_theory)): states that let $G$ be a finite group, and $p$ a prime dividing $|G|$, then $G$ contains a subgroup of order $p$.

Note: when the group is *abelian*, i.e. the group operation supports commutativity, the group operation is written mostly additively.

## Group Homomorphisms
Let $G,G'$ be two multiplicative groups, and $\varphi:G\to G'$ is a map such that $\forall a,b \in G,\ \varphi(ab)=\varphi(a)\varphi(b)$.

Examples:
- the map $\varphi:Z^{+} \to G$ defined by $\varphi(n) = a^{n}$, where $a$ is a given element of $G$
- the sign homomorphism $\sigma: S_{n} \to \{\pm 1\}$ that sends a permutation to its sign

Group homomorphism determines two important subgroups: kernel and image
- Image of a group homomorphism is the image of the map $\varphi$, $\text{im}\,\varphi$
- Kernel is the element in domain G that maps to identity element $\varphi(a)=1$

> [!note] Special kernel groups
> - Kernel of determinant homomorphism $GL_{n}\to\mathbb{R}^{\times}$ is the **special linear group** $SL_{n}(\mathbb{R})$.
> - Kernel of sign homomorphism $\sigma:S_{n}\to\{ \pm1 \}$ is called **Alternating group** $A_{n}$

**Left Coset**: if $H\leq G$ and $a\in G$, notation $aH$ stands for left coset of $H$ in $G$, and denoted as $aH=\{ g\in G\ |\ g=ah \text{ for some } h \in H  \}$

**Normal subgroup**: A subgroup $N\leq G$ is a normal subgroup if for $a\in N$ and $g\in G$, conjugate $gag^{-1}\in N$.
> **Prove** Kernel of a homomorphism is a normal subgroup.
- $SL_{n}$ is a normal subgroup of $GL_{n}$
- $A_{n}$ is a normal subgroup of $S_{n}$
- not all subgroups of non-abelian group is normal. For example, $S_{3}$

**Center** of a group G, often denoted by $Z$, is the set of elements that commute with all elements of G. $Z=\{ z \in G\ |\ zx=xz \ ,\forall x \in G \}$.
- Center of group $SL_{n}$ is $\pm I$
- Center of $S_{n}$ is trivial group for $n\geq 3$

## Group Isomorphism
An isomorphism $\varphi:G\to G'$ is a bijective group homomorphism such that $\varphi(ab)=\varphi(a)\varphi(b)\ ,\forall a,b\in G$.

Example
- Exponential map: $e:\mathbb{R}^{+}\to \mathbb{R}$ from additive group to multiplicative group of real numbers
- set $\mathcal{P}$ of $n\times n$ permutation matrices, then map $\varphi:S_{n}\to P$ is an isomorphism

> Prove $\varphi$ is an isomorphism, then $\varphi^{-1}$ is an isomorphism. $\varphi$ is bijective implies $\varphi^{-1}$ is bijective. Show that $\varphi^{-1}$ is a homomorphism.

**Isomorphic class**: set of all groups isomorphic to a given group G form *isomorphic class* of $G$. Two groups in an isomorphic class is isomorphic.
- Finding all isomorphic groups to a group is too difficult, but easy for some groups like finite cyclic group of prime order p.
- **Automorphism**: isomorphism from $G\to G$. Example: Conjugate by $g$ is an automorphism.
	- All automorphism of cyclic group of order 10 – Automorphism means group operation is preserved. So, a generator must also be a generator after the morphism.
	- All automorphism of Symmetric group $S_{3}$ – Since this isn't a cyclic group, but contains many partitions. Each generator of a partition must map to the other.

## Equivalence relation

Relation defined $a \sim b$ on a set $S$ such that following three axioms holds between two elements $a,b$:
- Reflexive
- Symmetric
- Transitive

Examples:
- Relation on a group defined by $a\sim b$ if a,b are elements with same order.
- Conjugacy

> Prove Equivalence class defines a partition on set S and conversely partition of S defines an equivalence relation.

Any equivalence relation can be defined by a map $\pi:S\to \bar{S}$ that maps an element $a\in S$ to its equivalence class $\pi(a)=[C_{a}]$. Set $\bar{S}$ is defined as the set of the equivalence classes of $S$.

The inverse image of an element $\bar{s} \in \bar{S}$ is the set $\{ s \in S\ |\ f(s)=t \}$. Also called *Fibres* of the map.

Example: map $f:G\to\mathbb{N}$ where $f(a)$ is the order of the element $a$ of $G$. Here, the fibres are set of elements with same order.

Equivalence relation defined by a group homomorphism $\varphi:G\to G'$ is referred to as *congruence*, $a \equiv b$ if $\varphi(a)=\varphi(b)$. Thus, $a \equiv b$ iff b is in coset $aK$ of G where $K$ is the homomorphism kernel.
